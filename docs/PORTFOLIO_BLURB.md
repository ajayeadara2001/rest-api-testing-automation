# Portfolio blurb

Built a REST API testing and automation portfolio project using Postman and PostgreSQL. The API suite covers authentication, end-to-end CRUD operations, dynamic token and booking-ID chaining, update checks, and deletion verification. A separate PostgreSQL test database demonstrates schema design, seed data, transaction-safe CRUD tests, joins, and SQL constraint validation. Documentation includes test matrices, execution-evidence guidance, and a clearly scoped API contract observation.

**Short GitHub description:** Postman REST API automation and PostgreSQL data-integrity testing with reproducible test suites and QA documentation.
